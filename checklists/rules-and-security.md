# 규정·보안 체크리스트

사람이 보는 문서입니다. 에이전트는 읽지 않습니다. 운영 규정과 시험 화면의 최신 안내가 항상 우선입니다.

## 공개 자료(키트 등)
- [ ] 공개 저장소에서 `git clone`으로만 가져왔다 (개인 PC 파일 업로드 없음)
- [ ] 키트가 결과물을 통째로 대신하지 않는다 (필요한 절차와 틀만 쓴다)
- [ ] 쓴 자료의 출처와 커밋 ID를 기록했다
- [ ] `kit/.git`을 지우지 않았다

## 데이터 보호
- [ ] 문제·파일·데이터·결과물을 외부로 보내지 않았다 (외부 API·업로드·외부 AI 포함)
- [ ] 키·토큰·비밀번호를 코드·로그·문서에 쓰지 않았다
- [ ] 개인정보를 요구 없이 결과물에 넣지 않았다
- [ ] 원본 데이터를 수정·삭제하지 않았다

## AI·환경
- [ ] 제공된 환경의 Codex만 썼고, 모델은 `/model`에서 안내된 것만 골랐다
- [ ] 개인 AI 서비스나 별도 AI 도구를 연결하지 않았다
- [ ] Codex 업데이트 질문은 거절했고, 설정·권한을 바꾸지 않았다
- [ ] 막힌 동작(쓰기 제한, 설치 차단 등)을 다른 경로로 우회하지 않았다
- [ ] 브라우저 자동화(Playwright 등)는 과제 안내가 허용한 것을 확인한 뒤에만 썼고, 별도 포트·임시 DB·합성 데이터로만 실행했다(설치·실행이 막히면 우회하지 않았다)

## Git
- [ ] Push를 하지 않았다
- [ ] `git add -A`나 `git add .`로 일괄 추가하지 않았다
- [ ] 로컬 커밋은 제공 환경에서 허용된 방식으로만 했고, 차단되면 생략했다

## 서술형 단계
- [ ] AI와 이 키트를 쓰지 않는다
- [ ] 복사·붙여넣기를 하지 않는다 (직접 입력)

## 막히거나 의심될 때
- 제한을 우회하지 않습니다.
- 오류 발생 시각, 화면 메시지, 수행 단계를 기록하고 "문제 신고"로 알립니다. 키·토큰 같은 비밀값은 적지 않습니다.
