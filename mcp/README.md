# MCP

**기본적으로 사용하지 않습니다.** 이 폴더에는 설정 파일이 없습니다.

이유
- 작업 환경의 MCP 설정창은 "서버 설정 JSON을 편집·저장"한다고만 안내돼 있고 **JSON 형식은 확인하지 못했습니다.**
- 외부 서버로 질의나 파일이 나가는 MCP는 외부 전송 모니터링과 도구 사용 제한 규정에 걸릴 수 있습니다.
- 과제 해결에 꼭 필요하지 않으면 설정 시간과 위험만 늘어납니다.

쓰고 싶다면
1. `PRETEST.md`의 MCP 항목대로 설정창의 실제 형식을 확인한다.
2. 어떤 데이터가 외부로 나가는지, 별도 모델에 연결되지 않는지 확인한다.
3. 비밀값은 설정 파일이나 공개 저장소에 넣지 않는다.
4. 확신이 없으면 쓰지 않는다.
