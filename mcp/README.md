# MCP

**이 키트는 MCP 없이 동작하도록 만들었고, 기본적으로 쓰지 않습니다.** 이 폴더에는 설정 파일이 없습니다.

응시 환경 안내(확인함)
- MCP 사용은 허용됩니다. 정해진 허용 목록은 없습니다.
- 응시 화면 왼쪽 MCP 탭에서 JSON을 편집해 저장하거나 터미널에서 설정합니다. 공개 저장소의 개인 MCP 설정을 `git clone`으로 가져와도 됩니다.
- 설정 후 Codex를 정상 종료(`/quit` 또는 `/exit`)하고 다시 `codex`로 실행해야 적용됩니다. 다른 터미널의 개발 서버나 감독 연결은 종료하지 않습니다.
- 별도 AI 모델 연결과 시험 자료·작업물의 외부 반출 용도로는 쓸 수 없습니다.

쓰고 싶다면
1. 어떤 데이터가 외부로 나가는지, 별도 모델에 연결되지 않는지 먼저 확인한다.
2. 비밀값은 설정 파일이나 공개 저장소에 넣지 않는다.
3. 과제 해결에 꼭 필요하지 않으면 설정 시간과 위험만 늘어나니 쓰지 않는다.
